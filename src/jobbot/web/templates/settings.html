Scanning

0 turns off automatic scans. Scans run while jobbot is running.

AI (Claude)

Claude reads each promising job against your resume and estimates how realistic an interview is. Scoring runs on new jobs after each scan, best estimated matches first.

Scoring many jobs adds up: Haiku costs a few cents per hundred jobs, Opus noticeably more. Prompt caching keeps your resume cheap to re-send.

Auto-apply

An agent opens the application in a browser and fills it in from your profile and resume. In review mode it stops before submitting and shows you every answer. It never solves CAPTCHAs, creates accounts or invents experience; it hands those cases back to you.

After that, approving re-runs the agent with your reviewed answers.

Notifications

Get new high-scoring jobs pushed to Discord, Slack, ntfy.sh or any webhook after each scan.

Hosted job board (GitHub Pages)

Scan on GitHub Actions and get your matches on an encrypted web page, for free, even while this computer is off. Save this config as a repository secret named JOBBOT_CONFIG, add a long passphrase as JOBBOT_PAGE_PASSWORD, then run the Job board workflow (steps in the README). Copy it again whenever you change your profile, filters or sources here.

It holds your profile, filters, sources and resume text, so keep it in GitHub secrets only. Auto-apply and status changes stay in this app.
